The gallery uses actual Flutter widgets with explicitly illustrative test data. It contains no live member account screenshots. Production flows continue to use Supabase. Runtime photography, fonts and animation attributions are in the app assets and Settings credits. The supplied reference image is retained here as design context and is not a runtime app asset.

Open HTML files locally to use the galleries; GitHub displays their source. New captures from the test command are still written to the local sibling `../design-review/implementation/` directory, so this committed folder is a review snapshot.
